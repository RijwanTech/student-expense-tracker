# 💰 Student Expense Tracker

A browser-based expense tracker designed for students to manage and monitor daily spending in Indian rupees (INR).

## 🚀 Features

- Add expenses with a date, category, and optional note
- View this month's total, today's spend, and average daily spend
- Search transactions and filter by category
- Delete entries and export transactions to CSV
- Save entries in browser local storage
- Display amounts in Indian rupees (INR)

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 💾 Data storage

Entries stay in the current browser profile and are not sent to a server. Existing saved amounts are displayed as INR; they are not converted from another currency. Export a CSV to keep a separate copy.

## ▶️ Run

Open `index.html` in a modern browser. No build step or dependencies are required.
